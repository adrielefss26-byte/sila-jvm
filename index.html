📍 Workspace:
🔥 Projeto:
Configure uma vez no Computador A e use o mesmo Workspace ID nos demais computadores para compartilhar os dados.
1
Cole as credenciais do seu projeto Firebase
Crie em console.firebase.google.com → Configurações do projeto → Seus apps → Web
2
Escolha um Workspace ID — mesma frase em todos os computadores
Funciona como uma senha compartilhada. Use letras, números e hífens.
Firebase já configurado — apenas mude o Workspace
📖 Guia de configuração do Firebase (passo a passo)
1. Acesse console.firebase.google.com e crie um projeto
2. No projeto: clique no ícone </> para registrar um App Web
3. Copie o objeto firebaseConfig que aparecer e cole no campo acima
4. No menu lateral → Firestore Database → Criar banco de dados
    → Selecione "Iniciar em modo de produção" → escolha região (southamerica-east1)
5. Em Firestore → Regras, cole e publique:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /sila_workspaces/{id}/{doc=**} {
      allow read, write: if true;
    }
  }
}
6. Pronto! Cole as credenciais acima, defina um Workspace ID e clique em Conectar.
